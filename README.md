# Java Beginner Programs

A collection of beginner Java programs I created in BlueJ during my first year at university, covering input, conditionals, loops, methods, and arrays.

## Programs

- **GuessTheNumber** — A number-guessing game.
- **MarksAnalyser** — Analyses a set of marks and gives the highest, lowest, and average.
- **MiniCalculator** — Performs basic calculations.
- **TemperatureConverter** — Converts temperatures between Celsius and Fahrenheit.
